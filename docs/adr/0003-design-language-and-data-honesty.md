# ADR 0003: 设计语言（白底、少小字、3b1b 版面）与“数据诚实”

date: 2026-10-25
status: accepted

## Context

使用者明确要求：浅色（纯白）背景、不要霓虹、画面里不要很多小字、3b1b 的版面（NFR-1、NFR-2、FR-9）。同时汇报会展示曲线和数值，示例数据一旦被误认为真实结果会造成误导。

## Decision

1. 画面纯白，低饱和配色，颜色只来自 `runtime/palette.ts`；每页最多 1 主色 + 1 辅色；颜色即对应关系（公式项、曲线、节点同色）。
2. 版面：图占满并居中；可选居中标题；底部一句旁白（每步一句，支持 `$…$` 行内公式）；不写段落、不写项目符号；细节放演讲者备注。
3. 尺寸单位是画面宽度的 1%（`--u`），图表用 viewBox 单位；文字不小于约 28 单位。强调靠出现、压暗其余、粗细，不用发光/渐变/毛玻璃。
4. **数据诚实**：示例数据如果不是真实测量/计算结果，页面上必须写“示意数据”；材料用 A/B/C 之类泛称；能真实计算的（softmax、注意力、凸包、能隙……）就用真实计算，不手填。
5. 文字里的数学符号一律用 `$…$`（KaTeX），不要直接打 Unicode 的 √、下标等。

## Considered Options

### Option A: 沿用 3b1b 的黑底
- Pros: 原汁原味。
- Cons: 与使用者明确的“白底”要求冲突；投影环境下白底更稳妥。

### Option B: 白底 + 同一套版面规则（选中）
- Pros: 满足要求；规则可写进文档让助手遵守。
- Cons: 所有默认的“黑底配色”都要自己重定义。

## Consequences

- 新组件必须遵守这些规则；示范页的小注是强制项而不是可选项。
- 配色表里没有的元素，晶体键会回退成灰色，需要时在 `palette.cpk` 补。
