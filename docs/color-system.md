# 项目默认配色

蓝橙主色 + 彩虹辅助色，适用于现有和后续讲稿。保留原有字体、字号和版式。
用户明确要求：浅色背景 #FBFAF8、暗色背景 #0F1218 均不改变。

| 角色 | 浅色 | 暗色 | 用途 |
| --- | --- | --- | --- |
| bg | #FBFAF8 | #0F1218 | 页面背景，固定 |
| fg | #11224E | #EDF0F4 | 正文、主要数字 |
| accent | #3166DD | #82A7FF | 标题、编号、链接、当前章节 |
| highlight | #FF7200 | #FF9A4D | 图形强调、当前步骤、重点填充 |
| highlightText | #A84600 | #FF9A4D | 普通字号的橙色文字 |
| muted | #5C6370 | #9AA0A6 | 次级正文 |
| detail | #687386 | #929DAD | 来源与说明 |
| done | #007F73 | #4DB6AC | 完成状态，配文字或符号 |
| surface | #FFFFFF | #192333 | 代码等内容面板 |

CSS 变量和 web/deck.js 的 PALETTES 必须同步。正文用 var(--fg)，标题用
var(--accent)，橙色重点文字用 .deck-highlight。Canvas/SVG/动画读取 palette 对应属性。
页面中不要直接写色值。橙底标签使用深色字；品牌橙不用于浅底小字。

## 图表

默认 series 顺序（对应 --plot-1 到 --plot-8）：
蓝 #3166DD、品牌橙 #FF7200、青绿 #009688、莓红 #AD1457、
深蓝 #1565C0、亮蓝 #448AFF、草绿 #8BC34A、琥珀黄 #FFC107。
默认先使用前两色做对比，按需要扩展；通常每图不超过 3–5 色。

rainbow 分类色库按参考图顺序：#448AFF、#1565C0、#009688、#8BC34A、
#FFC107、#FF9800、#F44336、#AD1457。暗色使用 PALETTES 中对应的提亮色。
同一数据对象跨页保持同色。浅底黄色、草绿等明亮填充需用深色边线、点形或标签辅助区分；
避免相邻两蓝或两橙作为唯一类别识别线索。颜色以外还需提供线型、符号或文字。

彩虹色用于离散类别；连续大小用单色明度变化，正负偏差用蓝—中性—橙。
科学约定的元素、CPK、晶体和结构配色保持原有含义；网页证据截图不重着色。

每页中性色约占 80%，蓝色约 15%，橙色约 5%，作为视觉参考而非硬性面积指标。
橙色优先强调一两处重点。明暗主题须分别验证文字可读性和图表辨识度。
